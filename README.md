# 🚌 バス運転ゲーム (Bus Driving Game)

実際の航空写真の上でバスを運転するブラウザゲームです。HTML 1ファイルだけで動きます。

## 特徴
- Google 航空画像の上を走る(Leaflet 使用)
- 場所検索(OpenStreetMap Nominatim)・現在地にバスを置ける
- 操作切替: タッチ版(スマホ / iPad)と キーボード版(PC)
- 車種: **AT バス**(6速オート、D/N/R 表示)と **MT バス**(6速マニュアル、クラッチ・ストールあり)
- ディーゼル風エンジン音(Web Audio、回転数連動)

## 遊び方
`index.html` をブラウザで開く(要インターネット接続)。

| | タッチ版 | PC版 |
|---|---|---|
| アクセル / ブレーキ | ▲ / ■ | ↑ W / ↓ S |
| ハンドル | ◀ ▶ | ← → A D |
| 駐車ブレーキ | - | Space |
| AT シフト | R N D ボタン | Z=R X=N C=D (Q/E で1段ずつ) |
| MT シフト | ▼ ▲ ボタン + クラッチ | Q/E または 1〜6、Shift=クラッチ |
| エンジン始動/停止 | 🔑 | Enter |

## GitHub Pages で公開
1. このリポジトリを GitHub に push
2. Settings → Pages → Source: `Deploy from a branch` / Branch: `main` `/ (root)`
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

## 注意
- 地図タイルは Google の非公式タイル URL を使用しています。個人利用・学習向けです。
  公開サービスとして運用する場合は Google Maps Platform(Map Tiles API)のキーを取得して差し替えてください。
- 場所検索は Nominatim の[利用ポリシー](https://operations.osmfoundation.org/policies/nominatim/)に従ってください。

## 追加機能
- ウィンカー(左/右/ハザード、点滅音あり・曲がり終わると自動で消える)
- 3D視点(斜め追従カメラ)。🎥で「3D追従 / 3D左側面 / 真上 / 北固定」を切替
- 前ドア・後ドアを個別に開閉(停車中のみ。開いていると発進できません)
- マルチタッチ対応(ハンドル+アクセル+クラッチなど同時操作可)

## v4 の変更点
- パーキングブレーキ(🅿 / Pキー)、エンジン始動音(クランキング→始動)
- ハンドルを円形ホイールで回して操作(タッチ版)、シフターは左・ウィンカーは右(大)
- 視点を「近く / 中間 / 遠く」+ 左側面 + 真上2種に拡充
- 走行中でもドアの開閉が可能
- ⚙ からドア開閉音・エンジン始動音を自分の音声ファイルに差し替え可能(ブラウザ内に保存)

## v5 の変更点
- ハンドルを大型化し、何回転も回せるように(約1.25回転で全舵、中央の数字で回転量を表示)
- 変速方式を AT / MT で切替可能(上部の AT/MT ボタン、M キー)。車体(大型/中型)とは独立
- 2速発進(AT: Dで2速から発進 / MT: 2速発進アシスト)
- ドア音のカスタムを 前ドア開/閉・後ろドア開/閉 の4種に分割

## v6 の変更点
- 車体サイズを 大型=9m / 中型=7m に変更
- 車体(大型/中型)と変速方式(AT/MT)を完全に独立して選べるように

## v7 の変更点
- 表示名を「AT」に統一
- ドアが閉まった後の発車放送(初期=チャイム+読み上げ、音声ファイルで差し替え可)
- 初期のドア音・チャイムを音声ファイル(WAV)として内蔵。⚙から書き出し可能
- サウンドセット 1〜4 に別々に保存・切替(⚙内のタブ / 上部の ♪ ボタン)

## v8 の変更点
- シフターを右、ウィンカー/パーキングブレーキを左に入れ替え
- ハンドルの切れ角を拡大(約1.25回転で全舵)し、旋回半径も小さく(低速で小回り)
- iOS で mp3 等の音声ファイルを読み込めない問題への対策(ファイル形式制限の撤廃、読込方法の追加、失敗理由の表示)

## v9 の変更点
- 高速バス(12m・最高速120km/h級)を追加。🚌で 大型→中型→高速 の順に切替
- シフト操作音(セレクター「ピッ」＋ミッション「ガコン」)。⚙で実録音に差し替え可能
- 音声合成装置(📟 / Bキー): 路線・停留所を自作し、停留所ごとに読み・放送文・放送音声ファイルを設定
  - 自動放送ON: ドアを閉めて発車 → 発車放送 → 次停留所の放送、ドアを開けると次の停留所へ進む
